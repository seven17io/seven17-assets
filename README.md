# seven17-assets

seven17-assets
Public image assets for Seven17 email newsletters and campaigns.
Used across multiple clients with a flat structure for quick linking.

Naming Format
client-campaign-email#-element.ext

Components
client – short name (heartzen, wildly, priority1, emcare2u, lifted)
campaign – short tag (newsletter, launch, promo, webinar)
email# – sequential number (1, 2, 3)
element – header, footer, button, etc.
ext – file extension (.png, .jpg, .gif)

Example Names
heartzen-newsletter-1-header.png
wildly-promo-2-footer.jpg
priority1-webinar-3-button.png
emcare2u-newsletter-1-header-v2.png

How to Upload & Get Public URL
Upload file into the newsletters/ folder.
Click the file, then Raw.

Copy the URL and edit it for public use:
https://github.com/seven17io/seven17-assets/blob/main/newsletters/heartzen-newsletter-1-header.png

Public (usable in emails):
https://raw.githubusercontent.com/seven17io/seven17-assets/main/newsletters/heartzen-newsletter-1-header.png

Notes
Keep file names lowercase and hyphen-separated.
Use -v2, -v3 for updated versions.
Delete outdated files to keep repo clean.
